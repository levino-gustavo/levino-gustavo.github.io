## 🎯 Sobre este repositório

Este é o código do **meu portfólio pessoal**: um site rápido, responsivo e sem frameworks, pensado para que recrutadores entendam **quem eu sou, o que já fiz e o que busco** em poucos segundos.

> 💡 **Ideia central:** todo o conteúdo mora em um único arquivo (`dados.js`). O layout nunca muda. Para atualizar o site, eu edito os dados, faço um commit e, em cerca de 1 minuto, está no ar.

## ✨ O que tem no site

| | Seção | O que mostra |
|---|---|---|
| 🏠 | **Topo** | Nome, cargo, selo de disponibilidade e botões de contato |
| 🙋 | **Sobre mim** | Bio curta e objetivos de carreira |
| 🧩 | **Projetos** | Cards com filtro por status: concluído, em andamento e planejado |
| 🧭 | **Trajetória** | Experiência, formação e cursos em linha do tempo |
| 🛠️ | **Habilidades** | Tecnologias, métodos e competências pessoais |
| 📬 | **Contato** | E-mail, LinkedIn, GitHub e WhatsApp |

Também tem 🌗 **tema claro e escuro**, 📱 **layout responsivo** e ♿ **foco visível no teclado**.

## ✏️ Como atualizar o conteúdo

1. Abro o `dados.js` (pode ser direto no GitHub, pelo ícone de lápis).
2. Altero a bio, adiciono um projeto ou atualizo um status.
3. Faço o **commit**.
4. O GitHub Pages publica a nova versão automaticamente. ✅

## 💻 Rodando localmente

```bash
git clone https://github.com/levino-gustavo/levino-gustavo.github.io.git
cd levino-gustavo.github.io
```

Depois é só abrir o `index.html` no navegador. Não precisa instalar nada.
